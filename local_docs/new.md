1. Блокер: install не может завершиться успешно

Новое, в аудите этого нет.

LaunchInfoBuilder::set_preferred_java_runtime (launch/mod.rs:143) не вызывается нигде — ни в init::install, ни в InstanceService::install, ни где-либо ещё. А build() начинается с:

let java_bin_path = self.preferred_java.ok_or(LaunchError::JavaRuntimeMissing)?; // :157

init::install (init.rs:95-98) заканчивается на .fill_defaults().build(). Значит любая установка отрабатывает все три стадии — качает манифест, библиотеки, несколько тысяч ассетов — и на последней строке возвращает Err(InstanceError::CreationFailed("no java runtime selected")). op.finish(Outcome::Failed), весь LaunchInfo выброшен.

Причём файлы на диске и строки в БД остаются, так что повторная попытка отработает быстро и упадёт на том же месте.

Чинится подключением того, что уже построено: Settings.java_runtime читается OptionsService::settings(id), JavaRuntime там полный. Нужно, чтобы install (или InstanceService::install) его достал и передал в билдер. Вопрос дизайна — кто именно: init::install сейчас не знает про OptionsService, и правильнее прокинуть JavaRuntime параметром из InstanceService::install, который до сервисов дотянуться может. Тогда же решается, что делать, если рантайм не выбран: отказывать до начала загрузки, а не после.

Отдельно: отказ должен случаться в начале, а не в конце. Сейчас порядок операций такой, что самая дешёвая проверка стоит последней.

2. Блокер: пути запуска игры не существует

launch_instance (execute.rs:9) не вызывается ниоткуда — единственная ссылка в закомментированном instance/mod.rs:65. У InstanceService нет метода launch. То есть LaunchInfo, ради которого весь install и затевается, некуда отдать.

Плюс в самой функции:

- .unwrap() на Command::output() (execute.rs:19) — если exec_path протух (java удалили), падает процесс;
- .output() вместо .spawn() — ждёт завершения игры и копит весь её stdout/stderr в память;
- возвращает (), ошибку сообщить некому;
- println!("{:#?}", args) и println!("{:#?}", output) — дамп всей командной строки и всего вывода игры.
